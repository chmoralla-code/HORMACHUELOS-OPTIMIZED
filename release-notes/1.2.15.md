# Hormachuelos Optimized 1.2.15

This release gives long AI answers a cleaner editorial rhythm while preserving the speed and safety work already shipped in the Optimized edition.

## Clearline AI replies

- **Quiet section dividers** appear before major headings, and model-authored Markdown rules are now preserved.
- **Stronger hierarchy** promotes standalone bold section labels and emphasizes short lead labels such as **Standard view:** or **Verification:**.
- **True nested lists** retain parent and supporting-detail relationships instead of flattening every bullet.
- **Refined code and file chips** make commands and shortened project filenames easy to recognize without allowing long paths to break the layout.
- **Readable technical blocks** add code-language headers, calm callouts, stronger tables, balanced headings, and more generous paragraph rhythm.
- **Discoverable reply actions** keep **Copy reply** visible in a subtle footer with a final hairline separator.
- **Model-side formatting guidance** asks every mode to use a short lead, descriptive sections, selective bold labels, and nested details for substantial reports.

## Responsive release gate

The release workflow now runs Playwright against a dedicated reply harness at:

- 1440×1000 desktop dark
- 720×960 narrow dark
- 390×844 mobile light

Those checks verify overflow, full-width section hierarchy, divider visibility, bold weight, nested indentation, code/file chips, callouts, and the Copy reply action. Screenshots remain attached to the GitHub Actions run as release evidence.

## Preserved from 1.2.14

- **Mission Control**
- **Workspace Time Machine**
- **Test & Fix Everything**
- Adaptive Director and maximized automatic mode routing
- Gemini CLI support and Client Success tools
- Desktop mode and the existing Preview Computer Use safeguards

## Safety and performance

- Raw HTML is still escaped before controlled Markdown transformations.
- Streaming Markdown remains throttled to the Optimized 20-FPS paint budget.
- Off-screen reply virtualization still starts only after final message height is measured.
- The Windows installer remains unsigned, so Windows may show **Unknown publisher**.
