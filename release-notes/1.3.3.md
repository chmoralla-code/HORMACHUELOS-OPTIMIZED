# Hormachuelos Optimized 1.3.3

## AGENTIC parallel coordinator

AGENTIC now runs up to six read-only evidence workers in parallel, with thinking split from tools.

- Large multi-area work can spawn more workers; a focused one-file fix still stays single-writer.
- Native and Cursor workers overlap through the shared host gate. The Director remains the only writer.
- The Workbench lanes are Thinking, Tools, and Agents. Tool cards appear without spawn animation.
- Workers inspect the real workspace before concluding. Claims without file paths are marked unverified. The Director re-reads cited paths before writing.
- The in-app Update button shows percent progress and restarts when the installer is ready.
- Adaptive remains the default. This update is not forced.

Workers inspect before the Director writes.
