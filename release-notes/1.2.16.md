# Hormachuelos Optimized 1.2.16

## Safe chat rollback

This patch connects typed rollback requests to the same conflict-aware Time Machine system already used by the Inspector.

### Fixed

- Typing rollback, roll back, revert, or undo now starts a protected rollback instead of producing an Ask-mode refusal.
- The rollback is handled by the desktop host, so it does not call an AI provider or consume model usage.
- Ask mode remains read-only for every ordinary write, edit, delete, shell, and download request.
- A confirmation dialog is still required before any protected files are restored.
- The newest reversible checkpoint is selected while empty Ask runs and already-rolled-back runs are skipped.
- Files edited after the AI run are preserved as conflicts rather than overwritten.
- Chat reports completed, partially completed, cancelled, busy, unavailable, and failed outcomes in clear language.
- Adaptive Director classifies direct rollback commands as guarded change requests.

### Safety boundaries

Short, explicit commands are recognized. Questions such as how do I rollback, negated requests such as do not rollback, and ambiguous file-scoped phrases are not executed automatically.
