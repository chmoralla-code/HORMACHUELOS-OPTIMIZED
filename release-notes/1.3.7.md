# Hormachuelos Optimized 1.3.7

## Maximized modes and recommended replies

Each mode now has a sharp job, and the AI's replies follow that job.

- Ask answers and explains. Project writes stay locked. Time Machine rollback stays host-routed.
- Plan produces a concrete plan the user can act on and waits for Apply. It does not start building.
- Research cites what it found. It does not invent verification or silently write production code.
- Build implements the change, verifies what it can, and reports what shipped.
- Adaptive remains the default. It routes Ask, Plan, Research, Parallel, or Build and skips unused phases so a question never becomes a write.
- AGENTIC stays opt-in. The Director is the only writer; workers stay read-only; think-first (~200 characters) is host-enforced before the first tool batch; batches are capped at three calls.
- Orchestrated and Thorough are real AGENTIC capability prompts. They are not extra write permission and not the Thorough execution profile.
- Parallel gathers useful independent evidence, not duplicate chatter.
- Replies lead with the result: short, mode-correct, no help-desk filler, no fake certainty.
- Adaptive remains the default. AGENTIC stays opt-in. Ask stays read-only. This update is not forced.

Modes stay distinct.
