# Hormachuelos Optimized 1.3.2

## AGENTIC Workbench spawn layout

AGENTIC now spawns in the chat stream like ordinary tool cards, while keeping the same Workbench features.

- Tools appear one by one as compact Cursor-style rows with lightning spawn, a `Ran N tools` batch header, and expandable arguments and results.
- After a run finishes or is cancelled, the spawned tools stay visible. Inspect run still restores Progress and Agents.
- Agents are compact expandable rows. Filter chips remain available when workers are present.
- Delivery Board, verification, contributions, Export Client Pack, keyboard tabs, and reduced-motion coverage remain.
- Adaptive remains the default. This update is not forced.

Spawned tools stay visible.
