# Hormachuelos Optimized 1.3.1

## AGENTIC mode persistence hotfix

v1.3.0 added the AGENTIC Workbench, but the desktop settings validator still rejected `agentic`, `orchestrated`, and `thorough`. Selecting AGENTIC failed with **Could not save mode** and rolled back to the previous mode, so the Workbench never started.

This hotfix lets AGENTIC save and reload.

- AGENTIC is a valid persisted permission mode.
- Orchestrated and Thorough are valid AGENTIC capabilities.
- A failed composer save restores the previous mode and capability, and shows a short backend reason instead of only "Could not save mode".
- Adaptive remains the default. This update is not forced.

AGENTIC mode can be selected and persisted.
