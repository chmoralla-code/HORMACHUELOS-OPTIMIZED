\n
01 // FRAME PATH

Less work between input and pixels.

\n
\n
STREAM.01

Incremental replies

Reasoning text appends in place, while expensive Markdown rendering is rate-limited during active streams.

\n
PREVIEW.02

Lean Source Lens

Pointer work is frame-coalesced, repeated targets are cached, and inspection waits for a stable hover.

\n
PAINT.03

Contained surfaces

Offscreen messages skip unnecessary painting, and perpetual blur, glow, and status animations are removed.

\n
STATE.04

Calmer persistence

Session writes are coalesced and quota failures back off, reducing serialization and retry churn.

\n
BUILD.05

Speed-oriented native build

The Rust release profile favors runtime performance with optimization level 3 and thin LTO.

\n
CURSOR.06

Preview control by choice

The hamburger menu offers Off, Auto, and On. Auto recognizes clear Playwright, browser-test, and Preview-debug prompts while preserving the Preview-only boundary.

\n
ANSWER.07

Ask Max reliability

Direct providers and Cursor detect blank completions, retry from preserved state, and require an organized user-visible answer after research tools finish.

\n
DESKTOP.08

Opt-in Desktop mode

The Preview sandwich menu has a Desktop mode Off/On control. When On, the agent can drive ordinary Windows apps, including Settings brightness, with a click-through cinematic AI cursor overlay. Simple searches chain click/type/Enter in one turn. Password managers, Security, terminals, and Hormachuelos stay blocked.

\n
PLAN.09

Plan, then Apply

Plan mode presents a plan and questions first. File writes stay locked until you confirm Apply. Choosing a stack is not Apply. A new request plans again.
